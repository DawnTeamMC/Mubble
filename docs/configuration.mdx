## Game rules

Mubble adds 1 game rule to the game:
- `super_mario:beep_block_cooldown`
  - **Description**: Sets the cooldown (in ticks) for beep blocks.
  - **Type**: `int` (min: 1)
  - **Default**: 80
## Ink

Ink painted by the Splatoon weapons lives on the faces of blocks, each face being split into 8×8 cells.
It sticks to any block with a collision shape (slabs, stairs and other partial blocks included), and gets cleaned
wherever a block is placed over it: a torch only cleans the middle of the face it stands on.

### Environment attributes

Like any [environment attribute](https://minecraft.wiki/w/Environment_attribute), these can be set per dimension type
or per biome by data packs, so that an arena can keep its ink forever while the rest of the world lets it dry off.
- `splatoon:gameplay/ink_lifetime`
  - **Description**: How long ink stays after it was last painted, in ticks. Zero or less keeps it forever.
  - **Type**: `int`
  - **Default**: 96000 (4 in-game days)
- `splatoon:gameplay/rain_washes_ink`
  - **Description**: Whether rain washes away the ink on the surfaces it falls on.
  - **Type**: `boolean`
  - **Default**: `true`
- `splatoon:gameplay/liquids_wash_ink`
  - **Description**: Whether liquids wash away the ink they touch, and keep ink from being painted under them.
  - **Type**: `boolean`
  - **Default**: `true`

### Block tags

- `splatoon:uninkable`: blocks ink does not stick to.

### Item component

The ink a weapon shoots comes from its `splatoon:ink` component, so any weapon can shoot any color:
```
/give @s splatoon:splattershot[splatoon:ink={color:"#F02D7D"}]
/give @s splatoon:splattershot[splatoon:ink={color:"#F0E22D",type:"splatoon:glitter"}]
```

### Resource packs

An ink type is drawn with the `<namespace>:block/ink/<path>` texture of the block atlas, tinted with the color of the
ink. Animated textures (with a `.mcmeta` file) are supported, which is how `splatoon:glitter` sparkles. Types without
a texture fall back on `splatoon:block/ink/normal`.
